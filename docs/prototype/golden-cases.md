## Pass rule

Each case must reproduce the approved calculation after agreed rounding and produce an acceptable recommendation. The five-case pass remains open until Sigrun reviews the recorded results and explicitly approves them. Passing this initial set authorizes expansion toward the broader 10–20 reconstructed-launch Phase 0 set; it does not authorize Phase 1 by itself.
